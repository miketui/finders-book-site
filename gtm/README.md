# Finder's Book GTM Autopilot v1

A guarded, repo-native autonomous growth operating system for The Finder's Book.

## Components
1. GTM Orchestrator master prompt
2. 30-day machine-readable state plan
3. Seven specialist agents: SEO, Content, Growth, Commerce, Analytics, Partnerships, Release/QA
4. `/gtm/` operating directory
5. Persistent metrics, experiments and approval state
6. GitHub Actions daily scheduler
7. GREEN/YELLOW/RED approval gates
8. Daily Founder Brief
9. Existing repository validation integrated into every run
10. Day-30 transition into Continuous Growth Mode

## Safety
This v1 does not directly send campaigns, spend money, publish listings/content, merge PRs, deploy production, or change prices. It prepares those actions and records explicit approval requests.

See `SETUP.md` for platform wiring.
